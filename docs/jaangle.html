Jaangle

Before Vibo there was TeenSpirit, later renamed Jaangle: a music player and library organizer for Windows, written by hand in C++ between 2003 and 2010. Many of Vibo's ideas come from it.

In 2026 it was renovated. It looks and works as it did, but it now builds with current tools and runs on current 64-bit Windows. Version 0.99.0 is the first release in fifteen years.

What it does

  • A music library built from your music folders and kept up to date, organized by artist, album, genre, year, collection and month added, with quick, full-text and advanced search, including accented and non-Latin names.
  • Playback through BASS (MP3, OGG, FLAC, WMA, AAC/M4A, APE, WavPack, MPC, AC3, MIDI, audio CD) with crossfading and a 3- or 8-band equalizer. Video through DirectShow, and a visualization pane.
  • Auto-continue: when the playlist runs out, it keeps going with random tracks from the whole library, the same artist, album, genre, year or collection, or the newest additions.
  • Tag reading and editing with TagLib, tags filled from file names and files renamed from tags. Ratings, comments and notes per track, and play history with statistics.
  • Album covers, artist pictures, lyrics and biographies downloaded automatically from Cover Art Archive, Deezer, LRCLIB and Last.fm, plus pictures found in the music folders. Web-search shortcuts (YouTube, Wikipedia, Discogs, Genius, Bandcamp and others) open in a built-in web pane.
  • A main window made of panes you arrange, 49 skins, more than 25 languages, a mini player, global hotkeys, Last.fm scrobbling and a music quiz built from your own library. On Windows 10 and later the current track shows in the Windows media overlay and lock screen.

How it is built

  • C++17 with MFC on the Win32 API, in 32-bit and 64-bit builds.
  • The window is a tree of panes, and an app-wide event bus tells each one when the track, the database or the settings change.
  • The library lives in SQLite with its own case-insensitive Unicode collation. Up to 0.98 it was a Microsoft Jet database (music.mdb).
  • Online information comes through one provider per web service behind a common interface, with a download queue and a local picture cache.
  • Scanning and online lookups run on worker threads that hand their results back to the window. Unit tests cover the database, tags, the job queue and the online providers.
  • The development notes from 2005–2006, written in Greek, are in the repository's Documents folder.

The 2026 renovation

The 2010 code was brought forward without changing what the program does:

  • Builds with Visual Studio 2026 with no warnings, with its libraries from vcpkg, and in 64-bit as well as 32-bit.
  • The library moved from Jet to SQLite, and tags to TagLib 2. BASS is current.
  • Background threads are no longer killed or polled, and network calls are cancelled on exit.
  • Online services that shut down long ago were replaced with current ones or removed.
  • New: the Windows media controls, a setup program, portable builds, and builds and releases on GitHub Actions.

What is different

  • Jaangle runs on Windows only. Vibo runs on macOS and Windows.
  • Jaangle has its online services built in, and the original ones shut down over the years; the renovation had to replace them in the code. In Vibo they are plugins, so one can be replaced without a new release of the app.
  • Jaangle was written by hand. Vibo was written by an AI coding assistant. See how it was made.

Running it today

The releases page has a setup program (64-bit) that keeps your settings and library in %APPDATA%\Jaangle, and portable zips (64-bit and 32-bit) that you unzip anywhere and run jaangle.exe; settings and library stay in that folder. The files are not code-signed, so Windows SmartScreen warns the first time you run them.

To build it yourself you need Visual Studio 2026 with C++, ATL/MFC, the Windows SDK and vcpkg. Run tools\fetch-bass.ps1 once, then build Jaangle.sln. The steps are in BUILDING.md. Problems go to the repository's issues.
